# Portfolio Assets

Add your static assets here so they are served from the site root.

## Recommended files

| File | Purpose |
|------|---------|
| `profile-icon.webp` | Profile photo used in the hero and navbar |
| `youtube.png` | YouTube clone project thumbnail |
| `movie.png` | CineSphere project thumbnail |
| `portfolio.png` | Portfolio project thumbnail |

## Notes

- If an image is missing, the site uses graceful fallbacks (initials avatar for profile, gradient placeholders for project cards).
- Keep images optimized for web (WebP/PNG, reasonable dimensions).
